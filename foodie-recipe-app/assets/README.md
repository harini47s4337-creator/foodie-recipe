# Assets Directory

This folder holds application branding assets for Expo:

- `icon.png` (1024x1024 px app icon)
- `adaptive-icon.png` (1024x1024 px for Android adaptive icons)
- `splash.png` (2048x2048 px splash screen)
- `favicon.png` (48x48 px web favicon)

In Expo Snack, remote image URLs are used out of the box so no local binary files are strictly required to run immediately.
